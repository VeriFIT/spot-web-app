The application has four modes of operation that you can select at its top:

<Terms>
  <Term name="Rewrite">
    for rewriting a formula (changing syntaxes, simplifying, removing some operators)
  </Term>
  <Term name="Study">
    for computing various properties of a formula
  </Term>
  <Term name="Compare">
    for comparing two LTL formulas
  </Term>
  <Term name="Translate">
    for constructing an automaton equivalent to a given formula
  </Term>
</Terms>
