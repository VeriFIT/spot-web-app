This web application is built using the services of
[Spot](https://spot.lre.epita.fr/) running on a shared computer. For serious uses,
you can answer similar questions using the
[command-line tools](https://spot.lre.epita.fr/tools.html), or by
[writing some C++ or Python code](https://spot.lre.epita.fr/tut.html).

The source code for this application can be found
[on our gitlab](https://gitlab.lre.epita.fr/spot/spot-web-app/), and is distributed
under the [GNU GPL v3](https://www.gnu.org/licenses/gpl-3.0.en.html) license.

For any question not answered in this small help text, or for reporting any bug,
please send an email to [the Spot mailing list](mailto:spot@lrde.epita.fr).
